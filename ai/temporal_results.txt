  Same split, same scaler, same threshold rule (99.5th percentile of the TRAIN
  score) and the same evaluate() as swat_detector.py, so the rows are directly
  comparable. Training windows are built inside train only, so the model is
  never tested on its own training data. Each window is scored at its LAST
  timestamp and the scoring windows may reach back into the train half for
  context, so every test row is judged from past samples only, never future
  ones. The counter column was dropped first: it is a plain row index, and
  leaving it in turns into a ramp that flatters whichever model happens to
  key on it, so this table and swat_results.txt will not match on PCA.
  On this file the temporal model came out ahead of PCA on PR-AUC, which fits
  the argument: a slow drift and a stuck sensor look fine instant by instant
  and only stand out as a trajectory. It is not a clean sweep though -- read
  the delay column too, the window model needs a whole window of bad samples
  before the error builds up, so it is slower to fire than the point models.
  Either way the seed spread above is worth reading before claiming a winner: a
  gap smaller than the spread is not a real difference on this few attacks.
